# URY Dashboard — Style Preview

This is a **visual-only preview** of the URY restaurant management dashboard UI, extracted from the [ury-erp/ury](https://github.com/ury-erp/ury) project's `frontend/` app.

It runs with mocked/sample data — there is **no live Frappe/ERPNext backend** wired up. Login, data persistence, and write actions (save, delete, etc.) do not actually work here; this exists purely to preview the dashboard's layout and styling.

For the real, functional application (POS, Kitchen Display, full ERP), see the upstream repo: https://github.com/ury-erp/ury
